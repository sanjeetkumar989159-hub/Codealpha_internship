# CodeAlpha C++ Programming Internship Projects

This repository contains my C++ programming projects completed as part of the **CodeAlpha C++ Programming Internship**.

The projects are designed to strengthen my understanding of **C++, Object-Oriented Programming, File Handling, Recursion, Backtracking, Data Structures, Input Validation, and Problem Solving**.

## 📂 Projects

### 1. CGPA Calculator

A C++ based CGPA Calculator that calculates semester GPA and overall CGPA based on course grades and credit hours.

#### Features

- Input number of courses
- Enter course name, grade and credit hours
- Grade validation
- Credit hour validation
- Semester GPA calculation
- Overall CGPA calculation
- Display individual course details
- Handles invalid inputs

#### Concepts Used

- C++ Functions
- Structures
- Vectors
- Loops
- Conditional Statements
- Input Validation
- Mathematical Calculations

---

### 2. Login and Registration System

A file-based authentication system that allows users to register and log in using a username and password.

#### Features

- User registration
- Username validation
- Duplicate username detection
- Password validation
- File-based credential storage
- Login authentication
- Error handling
- Menu-driven interface

#### Concepts Used

- Functions
- File Handling
- Strings
- Loops
- Conditional Statements
- Input Validation

> Note: This is an educational internship project. Production authentication systems should use secure password hashing and appropriate security practices.

---

### 3. Sudoku Solver

A C++ Sudoku Solver that uses **Backtracking** to solve a standard 9×9 Sudoku puzzle.

#### Features

- 9×9 Sudoku grid
- User input
- Empty cells represented by `0`
- Row validation
- Column validation
- 3×3 subgrid validation
- Backtracking algorithm
- Invalid puzzle detection
- Displays the solved Sudoku

#### Concepts Used

- 2D Arrays
- Recursion
- Backtracking
- Functions
- Conditional Statements
- Algorithmic Problem Solving

---

### 4. Banking System

A menu-driven Banking System developed using **Object-Oriented Programming in C++**.

#### Features

- Deposit money
- Withdraw money
- Fund transfer
- Balance management
- Account details
- Transaction history
- Input validation
- Error handling

#### Classes Used

#### Concepts Used

- Encapsulation
- Constructors
- Vectors
- Functions
- Transaction Management
- Input Validation
